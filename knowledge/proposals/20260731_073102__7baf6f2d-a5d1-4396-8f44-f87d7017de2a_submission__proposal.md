## Candidate reusable patterns

1. **False f2p from patch-only promotion** — Listing tests from `tests.patch` as fail-to-pass without NOP/unsolved verification can invent false f2p when the base already implements partial APIs or related behavior. Confirm each f2p fails before the fix and passes after.

2. **Instruction ↔ oracle/tests for eval/parse claims** — Claims about inline evaluation, `parse_type`, or similar parse-time behavior must match what the oracle implements and what tests assert. Wrong or overstated claims are Fixable instruction/oracle/test alignment defects.

3. **Reflog blocks Fixable preflight** — Leftover `.git/logs` (reflog) fails Fixable packaging preflight. Clear reflog/logs as part of Git hygiene before ZIP; do not leave mode-only dirt or `__pycache__` either.

4. **Internal kwargs as faithfulness overreach** — Asserting or requiring internal helper kwargs (e.g. `handle_list_and_dict`-style flags) that the instruction never states is test faithfulness overreach. Keep tests on documented/observable contracts only.
